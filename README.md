# AI-Powered Smart Logistics Intelligence Platform

An AI-driven logistics analytics platform for delivery delay prediction, ETA estimation, risk analysis, and business intelligence using Machine Learning, SQL, Power BI, and Flask.

## Features

- Delivery Delay Prediction
- ETA Prediction
- Risk Score Engine
- Logistics Analytics Dashboard
- Power BI Reporting
- Flask Web Application

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-Learn
- MySQL
- Power BI
- Flask
- Git & GitHub
